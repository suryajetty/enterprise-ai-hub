# Day 65 — Evaluating RAG Pipelines (RAGAS Framework)

RAGAS (Retrieval-Augmented Generation Assessment Suite) is a lightweight framework to validate retrieval quality, answer correctness, and end-to-end latency.

## Key metrics

- **Retrieval precision@k** — how often the top-k contains supporting evidence.
- **Generator fidelity** — factual correctness of model outputs given correct evidence.
- **Cost per query** — token usage + provider cost.

## Continuous evaluation

- Run nightly synthetic queries and record drift in retrieval quality.
- Use human-in-the-loop sampling for low-confidence responses.

## Example test flow

1. Seed the test set with known Q/A pairs.
2. Measure retrieval recall and generator correctness.
3. Fail the pipeline if recall or fidelity drop below thresholds.
