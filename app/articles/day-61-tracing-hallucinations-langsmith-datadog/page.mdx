## Day 61 — You Can’t Fix a Hallucination You Can’t Trace

Hallucinations are inevitable. The key is to capture enough context to reproduce, triage, and fix them: prompts, retriever results, embeddings, model choice, and prompt templates.

## What to log

- Full prompt and prompt template id
- Retriever top-k ids and scores
- Model name, temperature, and token usage
- Final response and any redaction/unmasking steps

## Tools

- LangSmith: for model tracing and example-driven debugging.
- DataDog/NewRelic: for latency, error rates, and SLO monitoring.

## Example instrumentation

1. Attach a unique trace id to each user request.
2. Emit structured events for retrieval and model calls.
3. Store a sample of traces in LangSmith for diagnosis.
