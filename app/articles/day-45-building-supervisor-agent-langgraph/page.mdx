# Day 45 — Building a Supervisor Agent with LangGraph

Supervisor agents orchestrate sub-agents and tools. LangGraph provides explicit state graphs, which makes supervisor behavior analysable and testable.

## Design steps

1. Define the typed state and allowed transitions.
2. Implement sub-agent interfaces (RAG, SQL, API tools).
3. Encode routing logic as conditional edges with guards.

## Example state type (pseudo)

```python
class SupervisorState(TypedDict):
	user_query: str
	history: list
	chosen_tool: Optional[str]

workflow = StateGraph(SupervisorState)
```

## Testing & safety

- Add step-count guards to prevent runaway loops.
- Simulate edge cases (ambiguous queries, tool failures) with unit tests.
