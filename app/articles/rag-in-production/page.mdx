## The Production Architecture

Notice how the LLM is shielded by the API Gateway and Guardrail nodes. This prevents PII leakage and controls costs.

## The Implementation

To connect to your vector database securely, use the following pattern:

```python
import os
from langchain_openai import AzureOpenAIEmbeddings
from langchain_community.vectorstores import Milvus

# Always pull credentials from secure environment variables, never hardcode
embeddings = AzureOpenAIEmbeddings(
    azure_deployment="text-embedding-ada-002",
    api_version="2023-05-15"
)

vector_db = Milvus(
    embedding_function=embeddings,
    connection_args={"uri": os.getenv("MILVUS_URI"), "token": os.getenv("MILVUS_TOKEN")},
    collection_name="enterprise_knowledge_base"
)
